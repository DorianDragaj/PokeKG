# KG Construction

Datasets, storage technology, and how the graph is built.
Report section 2 (KG Construction); **LO4**, **LO5**, **LO7**.

## Contents

```
src/extract.py                 PokéAPI extraction + Gen 3 projection + validation
src/transform.py               dataset -> RDF, using the ontology's vocabulary
src/load.py                    SHACL validation, then bulk load into Fuseki
ontology/pokemon.ttl           the TBox: classes, properties, axioms
ontology/shapes.ttl            SHACL shapes checked before every load
data/raw/pokeapi_dataset.json  the extracted dataset (committed, 0.3 MB)
data/raw/cache/                verbatim API responses (git-ignored, rebuildable)
data/rdf/base.ttl              generated by transform.py (git-ignored)
```

## How to run

From the repository root:

```bash
make install
make up
make transform
make load
```

`make install` is needed once, `make up` starts Fuseki, `make transform` turns
`data/raw/pokeapi_dataset.json` into `data/rdf/base.ttl`, and `make load`
SHACL-validates before loading the ontology, shapes and data graphs.

`make transform` reads the committed dataset, so the pipeline is reproducible
without network access. `make extract` rebuilds that dataset from PokéAPI and is
only needed to widen the scope: the first run downloads ~1,300 documents (about
20 s), every run afterwards reads the on-disk cache and takes ~2 s. Delete
`data/raw/cache/` to force a fresh download.

## Dataset

Source: **PokéAPI v2**, <https://pokeapi.co/api/v2> (stable public API).

| | |
|---|---|
| Pokémon | 365 (Gen 1–3, ids 1–386, 21 legendary/mythical excluded) |
| Types | 17 (Fairy excluded, introduced in Gen 6) |
| Damaging moves | 174 (level-up only, Gen 1–3 version groups) |
| Evolution edges | 184 |

PokéAPI serves current (Gen 9) values, so the extractor projects types,
abilities, the type chart and move stats back to **Generation 3**. Every change
is recorded under `projection.changes` in the output file. See
`pokekg/generations.py` for the two historical-data conventions involved.
